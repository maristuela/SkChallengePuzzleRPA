# 📊 Puzzle BI: Аналитика на естественном языке

**Puzzle BI** — это интеллектуальный чат-бот для бизнес-аналитики, который превращает вопросы на естественном языке в интерактивные дашборды. Проект разработан для кейса «Автоматизация организаций с помощью программных роботов и чат-ботов с ИИ».

## 🚀 Ключевые возможности

*   **Text-to-SQL:** Бот понимает запросы на русском языке и самостоятельно генерирует SQL-запросы к базе данных PostgreSQL.
*   **Умная агрегация:** Все вычисления (суммы, отклонения, проценты) производятся на стороне `pandas`, что позволяет гибко менять логику без повторных запросов к БД.
*   **Интерактивные дашборды:** Автоматическое построение до 4 графиков (Plotly) с KPI-карточками.
*   **Диалог с данными:** Прямо в чате можно попросить добавить колонку, удалить разрез или перестроить график.
*   **Живые фильтры:** Панель фильтров с поиском, мультивыбором и ползунком для дат. Пересчет графиков происходит мгновенно без нагрузки на БД.
*   **Сохранение и экспорт:** Возможность сохранять дашборды в личную панель и экспортировать их в PNG, HTML или CSV.
*   **Генерация инсайтов:** Бот автоматически пишет краткое текстовое резюме с ключевыми выводами по данным.

## 🛠 Технологический стек

*   **Язык:** Python 3.10+
*   **Фронтенд:** Streamlit
*   **База данных:** PostgreSQL (SQLAlchemy + psycopg2)
*   **Обработка данных:** Pandas, NumPy
*   **Визуализация:** Plotly
*   **LLM:** GigaChat API (генерация SQL, конфигураций графиков и инсайтов)
