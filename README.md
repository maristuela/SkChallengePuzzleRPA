# SkChallengePuzzleRPA
BI чат-бот с интерактивными дашбордами: пользователь пишет запрос на естественном языке — бот достаёт данные из БД, строит единую таблицу, добавляет вычисления (отклонение, % выполнения, доля, ТОП-N) и собирает живой дашборд с KPI, фильтрами и графиками Plotly. Дашборды сохраняются и восстанавливаются.
